# CLAUDE.md

Use `AGENTS.md` as the primary instruction file for this repository.

- Main repo instructions: `AGENTS.md`
- Where things are: `APP_SCHEMA.md`
- Why they are that way: `DECISIONS.md` — read the matching section before changing behaviour

When routes, shared components, data modules, or feature relationships change, update `APP_SCHEMA.md` in the same change. When a *rule* changes, update `DECISIONS.md` instead — keep rationale out of the map.
